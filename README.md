# ASIR Linux Admin

Repositorio de prácticas de administración de sistemas Linux para el ciclo de ASIR.

## Objetivo

Documentar y practicar tareas reales de administración de sistemas Linux:

- Gestión de usuarios y grupos
- Permisos y propietarios
- Servicios con systemd
- Logs del sistema
- Red básica en Linux
- SSH
- Firewall
- Automatización con Bash
