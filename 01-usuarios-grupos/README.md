
# Práctica 01 - Usuarios y grupos en Linux

## Objetivo

Practicar la gestión básica de usuarios y grupos en un sistema Linux.

## Comandos utilizados

- `whoami`
- `id`
- `cat /etc/passwd`
- `cat /etc/group`
- `sudo adduser`
- `sudo useradd`
- `sudo passwd`
- `sudo groupadd`
- `sudo usermod`
- `sudo gpasswd`
- `sudo deluser`
- `sudo userdel`
- `sudo groupdel`
